# Data dictionary

| File or column | Meaning |
| --- | --- |
| inputs/mall_facts.md | Mall, unit, lease, and directory information. |
| inputs/foot_traffic.csv | Hourly passing visits in a sample week. |
| foot_traffic.day_of_week | Day name for the observation. |
| foot_traffic.hour | Hour starting time, in 24-hour format. |
| foot_traffic.visitors | Passing visits during that hour. |
| inputs/competitors.csv | Existing shops in the mall. |
| competitors.name | Shop name. |
| competitors.what_they_sell | Main goods or services sold. |
| competitors.average_price | Typical purchase price in US dollars. |
| competitors.hours | Shop opening hours. |
| competitors.location_in_mall | Shop position in the mall. |
| inputs/shopper_survey.csv | Individual shopper responses. |
| shopper_survey.age_group | Respondent's age range. |
| shopper_survey.would_buy | Product the respondent would consider buying. |
| shopper_survey.max_price | Respondent's highest stated purchase price in US dollars. |
| shopper_survey.visit_day | Day on which the respondent visited. |
| inputs/cost_list.md | Supplier prices and payment terms. |
